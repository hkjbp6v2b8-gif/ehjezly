# ⏱️ مشروع تطبيق "احجزلي Pro" المتكامل من الالف إلى الياء

تطبيق خدمي متكامل لإدارة وحجز المواعيد الفورية في المحلات والعيادات ومراكز الخدمات (مثل صالونات التجميل ومراكز غسيل السيارات) بدون وقت انتظار.

## 📁 هيكلية ومكونات المشروع:
1. `frontend/index.html`: واجهة الرسومية الكاملة للزبون ولوحة التاجر معا تدعم اللغة العربية.
2. `frontend/styles.css`: تنسيقات المظهر والشبكة الذكية المتجاوبة مع شاشات الهواتف والويب.
3. `frontend/app.js`: منطق التحكم التفاعلي لإتمام الحجز وجلب البيانات الفورية.
4. `backend/server.js`: كود السيرفر الخلفي عبر بيئة Node.js لاستقبال وحفظ الحجوزات.

## 🚀 طريقة التشغيل الفورية:
* لتجربة واجهات التطبيق فوراً على هاتفك أو حاسوبك: فقط قم بفتح ملف `frontend/index.html` في أي متصفح ويب وسيعمل التطبيق بكفاءة تامة وبالاعتماد التلقائي على الذاكرة المحلية المستقرة المحاكية للسيرفر.
* لتشغيل خادم الاستقبال المطور (Node.js): قم بالدخول لمجلد الـ `backend` عبر الـ Terminal ونفذ الأوامر التالية:
  ```bash
  npm install express cors
  node server.js
  ```

## 🔼 طريقة الرفع لـ GitHub بضغطة واحدة:
1. أنشئ مستودعاً جديداً (Repository) على حسابك في موقع GitHub.
2. اسحب كافة الملفات البرمجية المفكوكة من هذا المجلد المضغوط وأسقطها في المتصفح واضغط **Commit changes**.
